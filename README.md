# Oxebots Interfaces

This package contains the interfaces used for the SSL Robocup league for the Oxebots team. The interfaces are used to communicate between the different components of the project such as the vision, referee, and strategy.

## Installation

To install the package, clone the repository into your colcon workspace and build it.

```bash
cd ${YOUR_COLCON_WORKSPACE}/src
git clone git@github.com:OxeBots/oxebots_interfaces.git
cd ..
colcon build
```
